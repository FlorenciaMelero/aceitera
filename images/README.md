# Carpeta de Imágenes

## Instrucciones

Coloca la imagen de cambio de aceite en esta carpeta con el nombre `oil-change.jpg`.

La imagen se usará como fondo suave (con baja opacidad) cuando los usuarios estén dentro de su cuenta.

**Archivo esperado:** `oil-change.jpg`

**Recomendaciones:**
- Formato: JPG, PNG o WebP
- Tamaño: 1920x1080px o superior
- Peso: Menos de 500KB para mejor rendimiento
